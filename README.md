# QQ Agent 天气关怀插件

`weather-care` · v1.1.1

睡前、起床和聊天时读取真实天气预报，提醒带伞、增减衣物或注意特殊天气，并可用 QQ Agent 当前模型与人设生成关怀语句。

## 功能

- 默认每天 22:00 睡前、00:00 新一天检查，可修改为自己的作息。
- 关注雨雪、雷暴、雾、阵风、冷热、紫外线和相邻两天明显升降温；定时到点固定使用 AI 生成关怀，天气平稳也发送；生成失败会在补查窗口内重试，不降级发送纯预报。
- 聊天中的晚安、起床、出门、穿衣、下雨和天气话题可触发查询与关怀，带冷却、每日次数限制与正常回复去重。
- 接收对象直接读取宿主 QQ 白名单，黑名单优先，白名单为空不发送。
- 无需天气 API 密钥；提供仅预览模式，发送未确认时停止自动重发。

## 安装

1. 下载本仓库，将 `plugins/weather-care` 整个文件夹复制到 QQ Agent 实际加载的插件目录。
2. 源码运行版通常为 `<QQ Agent 根目录>/plugins/weather-care/`；Windows 安装版通常为 `<安装目录>/resources/app/plugins/weather-care/`。入口中的 `../../src/` 必须指向宿主源码目录。
3. 在 QQ Agent「插件」页找到「天气关怀（睡前与起床）」，设置城市并保存。开启文件热重载时会自动加载。空城市暂停后台提醒。

这是宿主插件，依赖 QQ Agent 的配置、模型、安全网络、发送队列及本机控制台接口，不能单独用 Node.js 启动。代理备用通道使用宿主提供的 `undici`。电脑、QQ Agent 和 QQ 需要保持运行。当前对照 Windows 安装版 QQ Agent 0.4.0 验证；其他版本内部接口兼容性尚未验证。

完整行为、去重与故障说明见 [插件说明](plugins/weather-care/README.md)，配置项见 [配置说明](plugins/weather-care/SETTINGS.md)。

## 数据与隐私

仓库仅包含插件源码、通用默认值、文档和测试，不含宿主配置、API 密钥、控制台令牌、QQ 账号/群名单、聊天记录、人设、运行状态或预览文件。默认城市和坐标均为空。

运行时会从宿主读取白名单与近期消息；启用 AI 关怀时，相关消息、天气和人设片段会交给宿主配置的模型服务。城市或坐标会发送至 Open-Meteo 查询天气；控制台令牌只在运行时从宿主读取，用于本机回环接口鉴权。运行数据由宿主保存在其数据目录的 `weather-care/` 下。

天气来源为 [Open-Meteo](https://open-meteo.com/)，属于模式预报，不是实况或官方预警，服务适用范围以提供方条款为准。

## 测试

使用 Node.js 22 或更新版本，无需安装额外依赖：

```sh
npm test
```

共 48 项检查。独立运行时执行 46 项，跳过 2 项宿主集成检查；设置环境变量 `QQ_AGENT_APP_ROOT` 为兼容宿主的 app 根目录（含 `src/` 和已安装的 `plugins/weather-care/`）可执行完整 48 项，并校验宿主清单格式。集成测试针对该宿主内已安装的插件；发布前另行比对运行源码一致性。测试使用临时状态与模拟天气、模型、QQ 发送接口，不发送真实 QQ 消息，也不证明真实账号投递成功。
