# 配置说明

打开 QQ Agent →「插件」→「天气关怀（睡前与起床）」→ 设置。页面中修改并保存即可，**不需要运行命令或修改代码**。

接收对象从 QQ Agent 的白名单读取。此插件不维护另一份 QQ 名单。

| 配置项（键） | 默认值 | 说明 |
|---|---|---|
| 天气城市 `city` | 留空 | 必填，例如重庆、北京。留空暂停后台提醒，正常聊天查询会询问地点。 |
| 国家代码 `countryCode` | CN | 中国 CN、新加坡 SG、日本 JP 等。 |
| 纬度 `latitude`、经度 `longitude` | 留空 | 可选，同时填写，解决同名城市和区县定位问题；城市仍填写用于显示。 |
| 睡前时间 `eveningTime` | 22:00 | 当天睡前检查今明天气。 |
| 新一天时间 `morningTime` | 00:00 | 在新一天刚开始提醒；可改为起床时间如 07:00，与睡前时间不能相同。 |
| 时区 `timeZone` | Asia/Shanghai | 中国北京时间；新加坡可设 Asia/Singapore。提醒时间、预报日期、每天次数统一使用此时区。 |
| 升降温阈值 `temperatureChange` | 5 | 1–30℃；比较相邻两天的最高温、最低温，不把当天昼夜温差当成降温。 |
| 偏热阈值 `hotTemperature` | 35 | 20–50℃；最高温达到就提醒。 |
| 偏冷阈值 `coldTemperature` | 0 | -40–20℃；最低温不高于此值就提醒。 |
| 阵风阈值 `windGust` | 50 | 20–150 km/h。 |
| 带伞概率阈值 `rainProbability` | 60 | 1–100%；天气代码显示雨雪/雷暴时也会单独提醒。 |
| 定时补查窗口 `catchUpMinutes` | 30 | 1–180 分钟；电脑恢复、网络恢复后，仅在窗口内补查。 |
| AI 关怀 `aiCare` | 开 | 使用 QQ Agent 当前模型和会话人设，会产生正常模型用量；关闭改用规则文本。 |
| 语气偏好 `extraStyle` | 留空 | 例如“简短温柔，别唠叨，偶尔使用颜文字”。 |
| 每天简报 `dailyBriefing` | 关 | 关闭时，定时仅在天气值得注意时提醒。 |
| 仅预览 `previewOnly` | 关 | 后台定时/聊天只生成预览文件；正常聊天的天气查询仍能回复。 |
| 聊天自动关怀 `chatEnabled` | 开 | 睡觉、起床、出门、穿衣、下雨、天气等候选词触发；AI 判断是否适合关怀。 |
| 聊天冷却 `chatCooldownMinutes` | 30 | 1–1440 分钟，同一会话后台关怀最小间隔。 |
| 等待正常回复 `chatGraceSeconds` | 20 | 5–120 秒，后台每 10 秒检查；已正常回复则不补发。 |
| 聊天每日上限 `chatMaxPerDay` | 6 | 1–50 次/会话/天；不影响两个定时点和正常聊天查询。 |

示例：重庆，23 点睡前提醒、次日午夜提醒，可把城市填“重庆”，睡前填“23:00”，新一天填“00:00”。如果想起床前提醒，则把新一天填“07:00”。

设置由宿主自动保存到数据目录 `config.json` 的 `skills.weather-care`。**插件目录内不另放 config.json**，否则宿主不会读取。修改时间不重置当天已发送记录。

暂时不用：在插件页关掉此插件；停止定时器和后台聊天检查，也会停用天气工具和提示词。
